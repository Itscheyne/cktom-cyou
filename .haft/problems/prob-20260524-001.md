# Persistent storage backend for Talos Linux / K8s homelab

## Signal

Talos Linux is immutable — no host-level storage daemons. Need a CSI-compatible persistent storage solution for workloads on Proxmox-hosted Talos nodes.

## Constraints

- Must work with Talos Linux (no OS package installs, no SSH, immutable rootfs)
- Must be CSI-compatible (standard PVC provisioning)
- Runs on Proxmox VMs (no bare-metal assumptions)
- Single homelab operator — no enterprise support budget

## Optimization Targets

- Operational simplicity (low maintenance burden)
- Data durability (survive single-node failure)
- Cost (no paid licenses)

## Observation Indicators

- Write throughput
- Recovery time after node failure

## Acceptance

CSI StorageClass provisioned, PVCs bound, data survives pod reschedule and single-node failure

## Blast Radius

All stateful workloads (DBs, Prometheus, any PVC consumer)

## Reversibility

low

## Characterization v1 (2026-05-24)

| Dimension | Role | Scale | Unit | Polarity | Measurement |
|-----------|------|-------|------|----------|-------------|
| talos_compatibility | target | ordinal | level | higher_better | native (works out-of-box, no Talos system extensions) / extension (requires Talos system extension) / unsupported |
| ops_complexity | target | ordinal | level | lower_better | low (helm install, minimal config) / medium (multi-component, some tuning) / high (dedicated nodes, significant ops burden) |
| data_durability | target | ordinal | level | higher_better | none (node-local, data lost on node loss) / replicated (N-way replication across nodes) / external (Proxmox storage backend, survives all node loss) |
| storage_efficiency | target | ordinal | level | higher_better | thin provisioned vs thick; replication overhead (3x for 3-way replication) |
| rwo_rwx_support | target | nominal | access modes | higher_better | which access modes CSI driver supports: RWO / RWX / ROX |
| maturity | target | ordinal | level | higher_better | CNCF graduation status + homelab community adoption evidence |

**Parity rules:** All variants evaluated on same 3-node Proxmox/Talos cluster. Storage disks are virtual disks (Proxmox-managed). No variant gets dedicated storage nodes unless that's its native model.
